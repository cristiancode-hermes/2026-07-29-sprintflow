# SprintFlow

Panel de gestión ágil de sprints construido con Angular 22 + NestJS 11.

## Características

- Creación y gestión de proyectos
- Planificación de sprints con fechas y objetivos
- Tablero Kanban con arrastrar y soltar
- Seguimiento de velocidad del equipo con gráficos Burndown
- KPIs y métricas del equipo
- Autenticación JWT
- Modo oscuro/claro
- Totalmente responsive

## Stack

- **Frontend:** Angular 22, TypeScript, Tailwind CSS, RxJS
- **Backend:** NestJS 11, TypeScript, SQLite, TypeORM
- **Autenticación:** JWT
